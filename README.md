# AI Resume Reader using NLP Pipeline


## Project Overview

AI Resume Reader is a Machine Learning and Natural Language Processing
project that predicts a candidate's job category based on their resume.
The project uses an NLP-based Machine Learning Pipeline with TF-IDF and
LinearSVC. The trained Pipeline is saved using Pickle and integrated
with a Flask web application.


## Technologies Used
- Python
- Natural Language Processing (NLP)
- Scikit-learn
- TF-IDF
- LinearSVC
- Machine Learning Pipeline
- Pickle
- Flask
- HTML
- CSS

  
## How the Project Works
Candidate Resume → NLP Processing → TF-IDF → LinearSVC → Predicted Job
Category
The TF-IDF vectorizer and LinearSVC classifier are combined into a
single Machine Learning Pipeline.


## Dataset
The project uses a resume classification dataset containing:
- 962 resume records
- 25 job categories
- Resume text and corresponding category labels

## Machine Learning Model
The project uses a combination of:
- TF-IDF Vectorization for converting resume text into numerical
  features
- LinearSVC for job category classification
- Scikit-learn Pipeline for combining the text vectorization and
  classification steps
- Pickle for saving and loading the trained Pipeline
The trained Pipeline is stored in the project as a Pickle file.


## Flask Web Application

A Flask-based web interface is included in the project.

Users can:
1. Paste a candidate's resume.
2. Click Analyze Resume.
3. Get the predicted job category.
4. Click Clear to remove the current resume and prediction.
5. Enter another resume and analyze it again.

## Model Performance
The current model achieved approximately 83% accuracy on the test
dataset.

Model performance can be improved further by using a larger and more
balanced dataset, additional text preprocessing, feature engineering,
and model tuning.


## How to Run
Install the required Python libraries, run the Flask application, and
open the application in a web browser using the local Flask address.
